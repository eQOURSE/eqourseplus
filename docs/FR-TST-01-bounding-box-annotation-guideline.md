# Bounding Box Annotation client guideline

This guideline applies to the Bounding Box Annotation skill-test bank under FR-TST-01. Give candidates this guideline before the timed test. Project-specific client annotation rules take precedence for client delivery work.

## Pedestrians wearing backpacks

Draw one pedestrian bounding box that includes a backpack worn on the person's back. Do not add a separate backpack instance label in this assessment. Keep the box tight around the combined visible extent of the pedestrian and worn backpack; do not add surrounding background or cast shadows.

This is the house convention tested by question 9 in the Bounding Box Annotation bank. It is a project rule, not a universal object-detection standard.
